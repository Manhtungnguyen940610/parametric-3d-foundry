# Parametric Under-Desk & Wall Multi-Cable Clamp (MakerWorld Customizer Ready)

## 📌 Model Overview
Keep your workspace clean, tidy, and wire-tangle free! This fully **Parametric Multi-Cable Clamp** is engineered specifically for MakerWorld's built-in Customizer and desktop OpenSCAD. Whether organizing thick power cords, HDMI cables, or thin USB-C wires, you can dial in the exact dimensions you need in seconds.

## ✨ Key Features
- **100% Zero-Support FDM Printing:** Smart self-supporting angles (no bridging > 4mm, zero steep overhangs). Print directly on the flat bed without wasting filament.
- **MakerWorld Customizer Compatible:** Easily change slot counts (1 to 8 cables), cable diameters (3.0mm to 12.0mm), and spacing using intuitive sliders.
- **Secure Snap-in Retention:** Engineered chamfered lead-in ramps allow cables to push in with a satisfying snap while preventing accidental pop-outs.
- **Dual Mounting Styles:**
  - **Screw Wings:** Countersunk holes for standard M3 / M4 wood or drywall screws.
  - **VHB Channel:** Flat bottom with dedicated adhesive recess for 3M VHB tape under desks or on walls.
- **Smooth Rounded Edges:** Ergonomic fillets prevent snagging wires and protect your hands.
